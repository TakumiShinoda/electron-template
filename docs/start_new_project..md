## Start new project

1. Clone repository 
```
$ git clone -b {branch name} https://github.com/TakumiShinoda/electron-template.git {project name}
```

2. Go to Project
```
$ cd {project name}
```

3. Set electron-template to upstream
```
$ git remote rename origin upstream
```

4. Add master branch for new project
```
$ git branch master
$ git checkout master
```
